Semaine-type (a remplir une seule fois)

Cette grille est votre semaine de reference. Le Planning annuel la recopie automatiquement sur toute la saison. Ecrivez un nom de salarie par case (plusieurs noms possibles, separes par « / »). Laissez vide si personne.

Astuce : tapez le debut d'un nom, la liste des salaries connus s'affiche automatiquement. Un nom qui ne correspond a aucun salarie sera refuse (pour eviter les fautes de frappe).
